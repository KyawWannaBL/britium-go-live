# Branch waybill, workforce and commission process

A branch manager opens Branch Office → Print branch waybills for saved, financially valid waybills physically in that branch's recorded custody. In-transit parcels stay unavailable until receiving acknowledgement. The normal print layouts, barcode/QR preparation, canonical Way ID authorization, source waybill scan reference and declared delivery charge are retained. The first release is recorded before the browser print dialog; cancellation or printer failure requires native Superadmin reprint approval. Branch managers cannot approve reprints or print invoices through this entry.

Branch Office → Branch workforce & commission monitoring shows the current active assignment roster, linked active mobile accounts and whether a worker is already on any dispatched or held trip. Assign or replace the crew through Review, scan & dispatch, using the existing branch restrictions. Master-data edits, account changes and employment transfers remain in the existing administrator/HR workflows. A busy driver or van must finish its current custody/handover process before reassignment.

For each Yangon business date, the commission panel reads existing pickup and delivery events. Pickup attribution uses the pickup source branch; delivery attribution uses the event's recorded wayplan branch. It does not infer old work from the employee's current branch, generate commission on page load, alter rates, or initiate payment. Unknown-source historical events and other operation types remain in the full HQ Finance report for investigation. Displayed total covers READY, PENDING, APPROVED and PAID event amounts; it is an accrued/recorded total, not an unpaid balance. Detail rows show event status separately from Finance decision. At most 500 details are shown, with a warning when truncated; totals cover all eligible events for that business date.

Yangon Finance opens Finance → Head Office daily branch Finance monitoring → branch, then the workforce panel; the existing Workforce Commission report retains evidence/wallet review and explicit sync actions. Review pickup collection and independently checked parcel photos, successful delivery proof, worker/payee identity, one matching unpaid wallet liability, correct amount and rate. Hold discrepancies. Review approval and any later payout remain separate actions under existing Finance authority.

Daily branch sequence: confirm roster and vehicle availability; receive/scan incoming custody; print valid first-release labels; plan and assign crew; scan and dispatch; record pickup/delivery evidence and exceptions; hand over COD with receipt references; submit cash count and expense/funding requests. HQ Finance checks branch reports and commission exceptions daily. No branch takeover date or cash receipt is created by this release.
