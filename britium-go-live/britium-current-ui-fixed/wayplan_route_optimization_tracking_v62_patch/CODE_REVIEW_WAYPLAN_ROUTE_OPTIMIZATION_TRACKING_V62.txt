ROUTING
- Mapbox Optimization determines stop order.
- Mapbox Directions recalculates that order for road geometry and per-leg metrics.
- Driving-traffic uses the selected departure time for Directions ETA calculation.
- Rider/Bicycle uses the cycling profile.
- Every saved stop contains sequence, leg distance, leg duration, cumulative metrics and ETA.
- Manual move-up/move-down changes require fixed-order recalculation before save.

MANIFEST
- Preview and print order are derived from saved ordered_stops.
- Original operational row data are merged by canonical delivery Way ID.
- Unmatched legacy rows are preserved at the end rather than silently discarded.

LIVE TRACKING
- Command Center reads existing live-location snapshots and subscribes to existing GPS tables.
- A 20-second poll provides continuity when Realtime is unavailable.
- Rider-to-next-stop road distance/time/ETA is recalculated with Mapbox Directions.
- Rider field tracking runs only when the route status is IN_PROGRESS.
- GPS sync is throttled to 15 seconds or 25 metres of movement.
- Authenticated account email is used as actor identity.
- New GPS hook uses SECURITY DEFINER RPC flow and contains no direct table write fallback.

SAFETY
- No backend SQL mutation is included.
- No route status is changed by the tracking map.
- No synthetic production event, GPS point, delivery or proof is generated.
- Existing review, dispatch, start-route and arrive-stop RPC flows are preserved.
- Installer creates a timestamped production backup before replacing files.
